# Classic Automata Toy 经典作品设计技巧与机构心法

借鉴英国 **Cabaret Mechanical Theatre (CMT)**、**Paul Spooner**、**Keith Newstead**、**Tim Hunkin** 与日本传统 **络繰人形 (Karakuri)** 的大师作品经验，优秀的木制自动木偶（Automata）不只是“零件在动”，而是通过**机械节奏控制、隐喻叙事与可感知的物理诚实感**让静态木雕产生生命力。

---

## 1. 节奏与戏剧张力设计（Timing, Dwell & Surprise）

机械动作最忌讳“全程等速单调往复”。经典大师总是把**停顿（Dwell）**与**突变（Snap）**写入凸轮和棘轮的几何轮廓中：

1. **蓄势与停顿（Pear / Egg Cam & Semi-Circular Cam）**
   - 梨形/蛋形凸轮把近半周设为贴近基圆的“静止期”，让海鸥、舞者先处于静谧蓄势状态，再在凸瓣经过时优雅抬头或展翅——**“静”让“动”显得更有呼吸感**。
   - 半圆凸轮与棘轮专门制造**“步进—凝视—再步进”**的顿挫感：例如指针在某个刻度精准停顿 1~2 秒，观众的视线才来得及聚焦到指示结果上。
2. **缓升骤落（Snail / Drop Cam — Paul Spooner 招牌技法）**
   - 用 $90\% \sim 94\%$ 的圆周以阿基米德螺线缓慢抬升顶杆，积累视觉紧张感，随后在 $6\%$ 的台阶处瞬间自由跌落。
   - 适合表现：青蛙突跳、铁匠砸锤、惊吓盒子弹出、角色突然眨眼或鞠躬。跌落瞬间的轻脆木头撞击声（“咔哒”声）也是经典 Automata 的魅力来源。
3. **非圆多边形的“脉冲叠加”（Polygon Cam）**
   - 用正三角形或正方形替代圆形驱动水平转盘，把单调的匀速旋转变成**旋转 + 三拍/四拍上下起伏**的复合律动（如螺旋桨起飞抖动、旋转木马波浪舞），视觉趣味成倍提升。

## 2. 动作错相与多连杆复合叙事（Phase Layering & Compound Linkage）

只用一根主轴（Camshaft）也能演出双人对手戏或复杂身体语言，核心在于**相位错开**与**多级刚体借力**：

1. **黄金相位差（$90^\circ \sim 180^\circ$ Phase Offset）**
   - *振翅海鸥与航标浮标*：主海鸥（`0°`）与海面浮标（`135°`）错相，形成“浪先托起船/标、海鸥随后借风展翅”的因果呼应，而非机械齐步走。
   - *偏心双凸轮交替*：`180°` 反向偏心，左轮抬起正转、右轮顺势脱离，交接瞬间平滑换向，不用齿轮也能实现**往复摇头/摆臂**。
2. **三段式刚体链借力（Keith Newstead 划船水手技法）**
   - 只用一根垂直推杆向上顶船底，如何让船身摇晃、水手同时前后仰身、双手还牢牢握桨划水？
   - **秘诀是“固定机架锚点”**：船底受推杆俯仰 $\to$ 水手坐在船上随船摇摆，但水手背部通过连杆拉向舞台后方一根**固定立柱（Anchor）** $\to$ 船往前倾时，固定锚点把水手拉向后仰 $\to$ 肩膀与船舷桨架（Oarlock）共同约束手臂与木桨做闭环三角联动。**一根推杆产生三种自然耦合动作，且手永不脱桨。**
3. **可调支点创造“性格差异”（Pegboard Fulcrum Tuning）**
   - 经典制作中常在箱体背板钻出一排黄铜插孔阵列（Pegboard），摇杆支点插得越低、越靠近连杆，动作幅度越急促尖锐（适合狂躁啄木）；插得高而远，则舒缓从容。

## 3. 传统木工防卡死与容差技巧（Woodcraft Tolerance & Reliability）

真实木制 Automata 要经得起观众连续摇动手柄数千次而不卡死，大师常用的机械“保险丝”包括：

1. **平底从动足（Flat-Faced Follower）必须大于偏心距**
   - 如果凸轮轮廓陡峭或偏心较大，细尖顶杆极易被侧向推力别卡在导向套里。采用直径足够宽的圆盘平底足（`footRadius`），并让凸轮边缘做微倒角（Bevel），可把侧向力消化在接触面滑动中。
2. **用“钉轮 + 开口灯笼针轮”替代精密锥齿轮**
   - 手工木工很难车出完美渐开线 90° 锥齿轮。达芬奇手稿与传统风车磨坊广泛采用**冠形插销轮（Pin-Wheel）+ 无底盖悬臂灯笼针轮（Open-Bottom Lantern Pinion）**：圆铜销与圆柱木笼啮合自带极大偏心容差，哪怕木材受潮微变形也绝不咬死。
3. **双棘爪互锁（Drive Pawl + Hold Pawl）**
   - 单棘爪在回程时无法阻止负载倒转；必须加装机架止动棘爪，在驱动爪回缩蓄力时咬住齿根，才能做到干净利落的“单向锁定”。
4. **摩擦驱动的“安全打滑”（Friction Drive Safety）**
   - 正交圆形/半圆/双偏心凸轮依靠高摩擦缘带抵接托盘底面，一旦上方人偶被外力意外卡住，摩擦面会自动微滑而不至于崩断木齿，同时在木轴孔内嵌黄铜衬套（Brass Bushing）大幅降低木对木摩擦阻力。

## 4. 舞台美学与“机械诚实感”（Stagecraft & Mechanical Honesty）

1. **双层叙事空间：上台演戏，下箱揭秘**
   - 上层舞台（Stage Deck）是纯粹的童话/讽刺剧场，色调轻盈、轮廓剪影清晰；下层箱体（Chassis）特意采用正面半透明/镂空橱窗设计，**把最精妙的铜轴、棘爪、双偏心交接过程坦诚展示给观众**——看到“它是如何做到的”本身就是 Automata 一半的乐趣。
2. **材质与视觉焦点锚定**
   - 主体采用温润浅色木（山毛榉/桦木）营造手工感，运动关节、轴套、枢轴用亮黄铜/钢杆形成材质对比；把**朱红/铁锈红（Crimson Accent）**专门留给关键叙事部位（鸟喙、螺旋桨叶尖、指示箭头、可拖拽调节红环），让观众一眼锁定“哪里在动、哪里可调”。
3. **经典题材与机构速查配方表**

| 经典题材 | 推荐驱动机构 | 关键参数 / 技巧 | 舞台表现 |
| :--- | :--- | :--- | :--- |
| **海上飞翔海鸥** | 蛋形凸轮 (`pear`) + 偏心副凸轮 | 副凸轮错相 $135^\circ$，平底大从动足 | 海鸥优雅蓄势振翅，浮标错拍随浪起伏 |
| **疯狂啄木鸟** | 曲柄摇杆四连杆 (`four-bar`) | 支点调低偏前，产生急回特性 | 喙部高速高频敲击树干，刚性背杆不穿模 |
| **海岸划船水手** | 四连杆 + 3 级船体锚点联动 | 固定后立柱牵引水手背部 | 船身纵摇、水手后仰划桨、双桨同步闭环 |
| **青蛙突跳 / 敲锤** | 蜗牛骤降凸轮 (`snail`) | $94\%$ 缓升 + $6\%$ 瞬间落差 | 极强的“蓄力—骤变”喜剧悬念 |
| **磨坊风车 / 旋转木马** | 冠形钉轮与灯笼针轮 / 锥齿轮 | 选 $1:1.5$ 或 $1:2$ 变速比 | 暴露式 90° 转向传动，风帆稳健旋转 |
| **占卜指针 / 时钟步进** | 棘轮 (`ratchet`) 或 半圆凸轮 (`semi-circular`) | 半圆凸轮配指示箭头；棘轮配双爪 | 清晰的「转动—精确停顿」间歇步进效果 |
| **抖动螺旋桨 / 摇头舞者** | 多边形正交凸轮 (`triangle`/`square`) / 双偏心 (`dual-eccentric`) | 螺旋桨随三拍/四拍起伏同升同降；双偏心实现左右交替摆转 | 旋转与垂直跳动/左右换向自然融合 |
